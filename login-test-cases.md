# Login Functionality Test Cases

**Project:** Login Page Testing  
**Module:** User Login  
**Tester:** QA Trainee

## Test Case 1: Login with valid credentials
- **Test Case ID:** TC_LOGIN_001
- **Objective:** Verify that a user can log in with valid credentials.
- **Precondition:** A registered user account exists.
- **Test Steps:**
  1. Open the login page.
  2. Enter a valid email and password.
  3. Click the Login button.
- **Expected Result:** The user logs in successfully and reaches the appropriate page.
- **Actual Result:** Not yet executed.
- **Status:** Not Run

## Test Case 2: Login with an invalid password
- **Test Case ID:** TC_LOGIN_002
- **Objective:** Verify that an incorrect password is rejected.
- **Precondition:** A registered user account exists.
- **Test Steps:**
  1. Open the login page.
  2. Enter a registered email and an incorrect password.
  3. Click the Login button.
- **Expected Result:** Login is rejected and an appropriate error message is displayed.
- **Actual Result:** Not yet executed.
- **Status:** Not Run
